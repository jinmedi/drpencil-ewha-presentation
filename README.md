# 닥터펜슬 소개 발표자료 — 이화의료원

이화의료원에서 닥터펜슬(Dr. Pencil)을 소개하기 위한 HTML 프레젠테이션입니다.

## 구성

- `index.html` — 발표 슬라이드 (단일 HTML 파일, 브라우저에서 바로 열기)
- `assets/` — 이미지, 폰트 등 정적 리소스

## 실행

```bash
# 로컬에서 보기
open index.html
```

GitHub Pages를 활성화하면 `https://jinmedi.github.io/drpencil-ewha-presentation/` 에서 바로 볼 수 있습니다.
